# Cutting plans and PDF

[Documentation home](../README.md) / [User Guide](README.md)

**Cutting Plans** turns the saved result into a document you can inspect, print or download. It includes the accepted layout edits from Optimization.

## Open your document

1. Finish an optimization and wait for automatic saving to complete.
2. Click the project's **Cutting Plans** tab.
3. Wait for the PDF preview to appear. Scroll through its pages and use the preview zoom controls as needed.
4. Review the parts list, materials and purchasing information, panel inventory, individual part drawings and cutting panel drawings.

If no current result is available, return to **Optimization**. If a result could not be saved, resolve the error there before making a document.

## Customize the document

In **Document settings**:

1. Under **Cover page**, edit **Document title** if you want a different PDF title. This does not rename your project. Clear your override to return to the project name.
2. Add an optional **Description**. Line breaks are preserved on the cover.
3. Click **Choose image** to add a PNG or JPEG cover image. Keep it at or below 2 MB. Use **Replace** or **Remove** to change it later.
4. Under **Page layout**, choose **Paper size**: **A4** or **A3**.
5. Choose **Portrait** or **Landscape**. Portrait is the default when no orientation was saved.
6. Click outside an edited text field to apply it and wait for the refreshed preview.

These settings are saved with the project. Empty optional fields do not leave placeholders on the cover. If a very long description does not fit, shorten it or choose A3. Use **Retry save** if a settings save fails.

## Download or print

- Click **Download PDF** to generate the file and hand it to your browser's download controls. Your browser decides where it is saved.
- Click **Print** to open the PDF in another tab. Use that viewer's print control. Allow the new tab if your browser blocks it; a print dialog does not necessarily open automatically.

Wait while a button shows **Generating PDF…** or **Preparing…**. Do not close the page during generation.

For a drawing's stated scale to be correct on paper, select **Actual size** or **100%** in the print dialog, with the matching paper size. Do not use a printer's fit-to-page option when relying on that scale. Individual part cells may be fitted separately; use the written millimeter dimensions as the authoritative measurements.

Purchasing values use known catalog reference prices. **N/A** means a price is unknown; it is not zero. A **TOTAL:** can include only the known prices, so do not treat it as a complete quotation when some prices are missing.

Opening, downloading or printing a document does not add offcuts to stock. Use the project's [Stock tab](stock.md) for that decision.
