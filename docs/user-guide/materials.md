# Materials and panels

[Documentation home](../README.md) / [User Guide](README.md)

Choose both what your parts are made from and which panels the project may use. A material such as MDF is different from a panel with a particular length, width and thickness.

## If your material library is empty

Create a supplier panel reference first:

1. Open **Catalog** in the main sidebar. The Home tile is labeled **Catalogue**.
2. Click **Add Supplier**, enter the supplier name and optional website, then click **Create supplier**.
3. Select that supplier and click **Add Product**.
4. Enter the panel name. Choose its **Material**. You can choose a built-in material or create one through the material picker.
5. Enter the panel's length, width and thickness in millimeters, and its grain direction if applicable.
6. Enter a price if known. Leave an unknown price blank; zero means the price really is zero.
7. Click **Create product**.

A catalog reference is something you could buy. Adding it does not say you own it, place an order or reserve a panel.

If you already own a listed product, use its **Add to stock** action, enter how many panels you own and confirm. You can also record owned panels through global **Stock**; see [stock management](stock.md#record-panels-you-already-own).

## Choose panels for the project

1. Open the project and click **Materials**.
2. In **Material library**, click a material name to show its panels. Search or filter the library if needed.
3. Tick the material's checkbox if you want it explicitly selected for Parts. Choosing an eligible panel also makes its material available to Parts.
4. Under **Stock**, tick the owned panels you want this project to use.
5. Under **Catalog**, expand a supplier and tick the panel references the project may use.
6. Check **Project selections** on the right. Remove an unwanted selection with its remove control.

Selections save automatically. There is no Save button. If a save fails, use the displayed **Retry** action and resolve it before leaving. Expanding a group or clicking a material name only changes what you are viewing.

## Check before continuing

- Choose at least one suitable panel source before optimizing.
- Parts and panels must use the same material and exactly the same thickness.
- Stock quantities limit how many physical panels are available. Catalog references do not have a project quantity field here.
- Offcuts generated by this project cannot be used as its own starting panels. They may be used by other projects.
- Removing a material selection does not delete existing parts. Review any material warnings in **Parts**.

You cannot create or edit catalog products inside project Materials. Return to **Catalog** for those changes, then come back to the project.
