# Projects

[Documentation home](../README.md) / [User Guide](README.md)

A project groups the materials, parts and cutting plans for one job. Start a separate project for another cabinet, workbench or batch of pieces.

## Create your first project

1. Open **Home** and choose **New Project**, or open **Projects** and click **New project**.
2. Enter a **Project name** you will recognize later.
3. Add a **Description** if useful. You may leave it empty.
4. Click **Create project**.
5. Start with **Materials** in the project header.

You can move between **Materials**, **Parts**, **Optimization**, **Cutting Plans** and **Stock** at any time. A printable cutting plan needs a successful optimization first.

## Return to a project

1. Click **All projects** in the project header to see the full list.
2. Use **Search projects** if needed.
3. Click a project to open it.

The sidebar's **Projects** link may return to the project you were working on. Use **All projects** when you want the list instead. Saved project data can be reopened after refreshing the page.

## Rename or describe a project

1. Find the project in **All projects**.
2. Open its three-dot actions menu and choose **Edit project**.
3. Change the name or description, then save the form.

Changing a PDF's cover title is separate from renaming a project. See [Cutting Plans](cutting-plans.md#customize-the-document).

## Delete a project carefully

1. Open the project's actions menu and choose **Delete project**.
2. Read the stock choices before confirming.
3. Choose **Keep current stock** to leave consumed panels and kept offcuts as they are. This is the recommended choice.
4. Choose **Restore initial stock** only if you want to reverse this project's stock changes and the application says it is safe.
5. Confirm only when you are sure. Export the project first if you want a portable copy of its parts and plans.

Restoration may be unavailable if another project has already used or changed an offcut. Deleting a project does not delete the shared supplier catalog. A project export does not back up physical stock history.
